# Decodability Is Not Validity

Code, results and paper source for **"Decodability Is Not Validity: Evaluating Nuisance Sensitivity in Language
Model Concept Probes"** (Ayal Klein).

Two concept probes can be equally accurate at predicting a concept from an LLM's hidden states while their scores
contain different mixtures of the target concept and a correlated nuisance attribute. We compare decodability with
discriminant evidence about one named nuisance per dataset — the score's dependence on the nuisance with the target
held fixed, and its response to input edits intended to change only the nuisance (filtered by two LLM judges and
compared against placebo edits) — across three public datasets, two LLMs and a population of linear concept
extractors, and compare development-set criteria for selecting extractors.

| dataset | target T | nuisance N | nuisance edits |
|---|---|---|---|
| [CEBaB](https://huggingface.co/datasets/CEBaB/CEBaB) | service sentiment | food sentiment | human counterfactual edits |
| [Bias in Bios](https://huggingface.co/datasets/LabHC/bias_in_bios) | surgeon vs. nurse | subject gender | pronoun / gendered-noun swap |
| [CivilComments-WILDS](https://huggingface.co/datasets/pietrolesci/civilcomments-wilds) | toxicity | mentions Muslim / LGBTQ people | identity-term swaps (both directions) |

Models: `Qwen/Qwen2.5-7B-Instruct`, `google/gemma-2-9b-it` (frozen; residual stream, 7 depths).

## Repository layout

```
src/dv/          data construction (data.py), extractors (extractors.py), metrics (validity.py), judge acceptance rule (judging.py)
scripts/         numbered pipeline, see below
results/         per-extractor metrics (pop_*.parquet), counterfactual variants (cfv_*.parquet), analysis tables (rev_*.csv),
                 implementation audit (AUDIT.md)
data/<ds>/       edit pairs (pairs.parquet), LLM-judge verdicts (judge*.parquet), token counts, CEBaB review families
paper/           LaTeX source; paper/tables/* and paper/tables/numbers.tex are generated by scripts/12_tables.py
```

Not included (large or regenerable): hidden-state activations (~10 GB), per-extractor raw scores (~110 MB), and the
derived dataset texts — `scripts/01*.py` rebuild the texts deterministically from the public datasets.

## Reproducing

```bash
pip install -r requirements.txt
export PYTHONPATH=src
python scripts/01_build_datasets.py          # unified (T, N) tables + edit pairs
python scripts/01b_civil_reverse_edits.py     # Christian -> Muslim edits for Civil
python scripts/01d_exclude_train_duplicates.py
python scripts/01c_placebo_edits.py           # placebo edits
python scripts/02_extract.py qwen7b           # GPU; also: gemma9b, and qwen7b:last (last-token readout)
python scripts/02c_judge_edits.py             # GPU; local judge (Qwen3-32B)
python scripts/02d_judge_edits_groq.py        # second judge (gpt-oss-120b via Groq); API key read from ~/.groq_key
for ds in cebab bios civil; do for m in qwen7b gemma9b qwen7b_last; do python scripts/03_fit_population.py $ds $m; done; done
python scripts/08_cf_variants.py qwen7b gemma9b qwen7b_last
python scripts/09_revision_analyses.py        # near-best, equivalence, correlations, selection, geometry, judges
python scripts/10_synthetic.py
python scripts/11_figures_rev.py && python scripts/12_tables.py && python scripts/13_pooling_ablation.py
python scripts/07_audit.py                    # implementation audit -> results/AUDIT.md
python scripts/02f_human_audit_sample.py      # blinded sample for human annotation of the edits
cd paper && tectonic -X compile main.tex      # or latexmk/pdflatex with bibtex
```

The LLM-judge verdicts used in the paper are included (`data/*/judge*.parquet`), so the analyses can be rerun without
re-judging. `scripts/run_after_gpu.sh`, `scripts/gq_*.sh` and the `02`/`03` scripts contain paths and a job-queue
wrapper (`gq`) from the shared lab machine they were run on; adapt them to your environment.
Scripts `04`–`06` belong to an earlier version of the analysis and are not used by the current paper.
